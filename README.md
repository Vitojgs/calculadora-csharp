# Calculadora em C#

Uma calculadora de consola desenvolvida em C# para a disciplina de Programação Orientada a Objetos. O programa executa operações matemáticas básicas de forma interativa, focando-se na validação robusta dos dados inseridos pelo utilizador.

## Funcionalidades

- Operações suportadas: Soma (`+`), Subtração (`-`), Multiplicação (`*`) e Divisão (`/`).
- **Validação de Inputs:** Utilização de `double.TryParse` para garantir que o programa não bloqueia ao receber caracteres inválidos.
- **Programação Defensiva:** Prevenção de exceções e tratamento de tentativas de divisão por zero.
- **Ciclo Contínuo:** Sistema de repetição (ciclo `do-while`) que permite efetuar vários cálculos consecutivamente sem necessidade de reiniciar a aplicação.

## Tecnologias Utilizadas

- **Linguagem:** C#
- **Ambiente:** .NET 8.0 SDK (Console Application)
